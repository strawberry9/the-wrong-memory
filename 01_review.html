Review

The Wrong Memory is an online open-source book and essay collection focused on memory safety, security vulnerabilities, and C programming semantics.

The text examines how the fundamental design of the C programming language inherently shifts the burden of maintaining memory invariants onto the programmer.

But it approaches this examination through a broader theoretical, critical, and essay-driven framework. Its individual themes—including vulnerability analysis, semantic invariants, memory-safe language design, and the contrast between C and Rust—are well established. What stands out in the book is the way these themes are connected. The result is an attempt to connect vulnerability analysis, programming-language design, and the programmer's mental model of memory safety. That connection is taken a step further in Appendix VI, which specifies CobaltC, a C-like systems programming language that makes many of the memory invariants discussed throughout the book explicit parts of the language's design.

The extensive use of AI (clearly acknowledged in the 'AI Disclosure', in the Preface) will likely spark some interesting conversations.

But this book deserves to be differentiated from "AI slop". AI slop implies low-effort, unedited generation meant only to clog search engines or waste a reader's time. The Wrong Memory is an AI-assisted technical essay. Instead of teaching you how to write C code, it steps back to examine the philosophy and architecture of failure, and seeks to give its readers a mental framework rather than just a checklist of syntax rules.

Seeing how transparently the book addresses its own creation makes its technical points about AI partnership in Appendix V carry even more weight.

Whether you agree with its perspectives on C and memory safety or prefer human-authored texts, it represents a substantial, structured, and technically grounded piece of writing.
