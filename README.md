This repository contains the manuscript for my first book, The Wrong Memory.

The book argues that many seemingly different memory-safety vulnerabilities in C are manifestations of a deeper problem: the violation of semantic invariants.

It develops this idea into a framework for understanding the relationship between C vulnerabilities, program semantics, and the design of memory-safe programming languages.

The book can be read online [here](https://strawberry9.github.io/the-wrong-memory/).
